# Galaxy One UI 9 Resource Monitor

A native, lightweight Android application designed specifically for Samsung Galaxy devices running **One UI 9 / Android 17**.

## ✨ Features
- **Thermal & Battery Dashboard**: Real-time battery temperature in °C with dynamic color-coded thermal alerts, charge/discharge current in milliamperes (mA), voltage, and health status.
- **RAM Monitor**: Live memory usage gauge with available RAM indicator.
- **Internal Storage Gauge**: Storage capacity and free space monitoring.
- **CPU & System Info**: Architecture (arm64-v8a), 8-core status, One UI & Android platform detection.
- **Zero Background Drain**: Pure on-demand monitoring. Consumes 0% battery and 0% CPU when closed.
- **100% Free & Open Source**: No ads, no trackers, no subscriptions.
